# SILTA Shops

Kelių e. parduotuvių sistema prekių ženklams SILTA, RAMU ir ZIBURYS. Viešos vitrinos dalijasi bendra technine baze, o valdymo centras leidžia administruoti katalogus, tiekėjus ir lankomumo duomenis vienoje vietoje.

## Funkcionalumas

- Atskiros prekių ženklų vitrinos
- Produktų katalogai, spalvų variantai ir nuotraukų galerijos
- Slaptažodžiu apsaugotas valdymo centras
- Parduotuvės lankomumo analitika
- Prisitaikantis dizainas telefonams ir kompiuteriams

## Technologijos

- React 19
- TypeScript
- Vite
- Vercel serverless API

## Paleidimas

```bash
npm install
npm run dev
```

Produkcinio build patikra:

```bash
npm run build
```
